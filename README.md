# SAITORA Static Website

Premium one-page static website for the Bulgarian digital studio SAITORA.

## Local Preview

Run this command from the project root:

```bash
python3 -m http.server 8080
```

Open the site at:

[http://localhost:8080](http://localhost:8080)

The website also works by opening `index.html` directly in a browser. No deployment, hosting setup, Firebase, Node, npm, framework or build tool is required.

## Structure

```text
index.html
assets/css/style.css
assets/js/main.js
assets/images/
robots.txt
sitemap.xml
README.md
```
